# Mission Status: Where Apollo Stands

The documentation teaches Kubernetes concepts independently of Apollo’s
runnable snapshots. Launchpad through Stage 7 are the supported local learning
path when used with Apollo11 commit
`7b693c9bae0a789dc9db8e0628c478fd0dd53e88`. The
[lab setup page](./labs/setup#clone-the-tested-lab-revision) explains how to
verify that revision.

Security, cloud operations, and later extension material are conceptual or
roadmap material unless a source snapshot explicitly says otherwise. Commands
in those sections describe evidence a future implementation should produce;
they are not supported setup instructions. A later snapshot does not
automatically inherit controls from an earlier one.

| Area | Status | Learner action |
| --- | --- | --- |
| Launchpad through Stage 7 | Supported local path | Read first; run the optional matching lab against the pinned commit. |
| Command Module security | Conceptual/planned | Study enforcement boundaries; do not expect example commands to succeed. |
| Lunar Orbit cloud and EKS | Conceptual/research boundary | Study ownership and recovery; do not create cloud resources from these docs. |
| Mission extensions | Roadmap | Treat names as possible future topics, not implemented capabilities. |
