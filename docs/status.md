# Mission Status: Where Apollo Stands

The documentation teaches Kubernetes concepts independently of Apollo’s runnable snapshots. Launchpad through Stage 7 are the supported local learning path. Security, cloud operations, and later extension material are conceptual or roadmap material unless a source snapshot explicitly says otherwise. A later snapshot does not automatically inherit controls from an earlier one; check its rendered manifests.
